**Kageyoshi-Noir**

A universal roblox script mostly vibe-coded. Offers are welcomed.

**Game compatibility**

Script has both universal features and targeted at specific games. Script was tested in Multicrew Tank Combat, Slap Battles, Build a Boat for Treasure and some random ragdoll games.

**Functionality**

Script has many universal and targeted features:
- Esp
- Walkspeed
- Jump power
- Fly
- Noclip
- Aim
- Babft autofarm
- SlapBattles helper
- Infinity Yield integration
- Simple Spy intergration
And many others.

**Compability**

Script was tested with Potassium and it should work with other modern executors as well. Currently supports only desktop devices(or emulators)
